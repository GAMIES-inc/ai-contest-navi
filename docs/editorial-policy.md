# ゆるコンテストなび 編集方針

更新日: 2026-07-11

## サービスの役割

ゆるコンテストなびは、初心者やライト層が「自分にも出せそう」と思えるコンテストを、公式情報にもとづいて見つけられる案内サイトです。

## 掲載する募集

- イラスト、アート、デザイン、AI画像
- 写真、動画、ショートムービー、AI動画
- 文章、エッセイ、企画、アイデア、漫画
- 音楽、工作、クラフト
- X投稿、ハッシュタグ投稿、キャンペーン
- 学生向け、初心者向け、地域・企業・学校主催の創作募集

## 掲載しない募集

- 公式ページ、募集要項、公式SNSのいずれも確認できないもの
- 締切、応募方法、主催者が著しく不明確なもの
- 権利侵害、公序良俗違反、詐欺的な誘導が疑われるもの
- 応募者に過度な費用負担や不利益を求めるもの
- 作品募集よりも商品購入・個人情報収集が主目的と判断されるもの

## 情報の優先順位

1. 主催者の公式募集ページ・募集要項
2. 主催者の公式SNS投稿
3. 主催者が指定する応募プラットフォーム
4. 信頼できる第三者メディア

情報が競合する場合は、より新しい公式情報を優先します。不明点は断定せず「公式ページで確認」と表示します。

## 記事のトーン

- 「初心者OK」「画像1枚でOK」など、根拠がある参加しやすさだけを表示する
- 煽りや受賞保証につながる表現を避ける
- PR掲載は必ずPR表記を行う
- 公式サイトと誤認される表現を避ける
- 締切・賞品・応募方法・権利条件は短く要約し、公式確認導線を必ず置く

## 画像の扱い

カード画像は原則として情報取得元の公式キャンペーン画像を使用します。出典URLと権利者を記録し、修正・差し替え・掲載停止の依頼には速やかに対応します。公式画像が取得できない場合のみ、ブランド共通のジャンル別画像を使用します。
